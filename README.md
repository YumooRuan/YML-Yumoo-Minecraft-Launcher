# YML-Yumoo-Minecraft-Launcher
YML（Yumoo Minecraft Launcher）是面向 Windows 10/11 x64 的 Minecraft Java 版启动器。支持原版、Fabric、Forge、NeoForge、Quilt、OptiFine 安装与启动；内置版本管理、下载中心、Java 运行时、模组/资源包/光影/整合包/地图管理，地图可通过 CurseForge 镜像免 Key 下载。提供模组冲突检测、PCL2 光影配置兼容、存档与 servers.dat 服务器编辑、离线/微软/外置登录、日志诊断、陶瓦联机与樱花 FRP 入口。单文件 exe 自带 Java 26，无需安装 Java；支持实例隔离、自定义图标、主题色、全局 Toast、测试启动、更新检查与 SHA-256 校验，GPLv3 开源。
